# TikTok onay demo videosu senaryosu (mp4/mov, en fazla 50 MB, 1-3 dk)

Kayıt sırasında adres çubuğunda `reblebi.com` görünsün (TikTok bunu başvurudaki web adresiyle eşleştirir).
Önce TikTok geliştirici portalında Reblebi uygulamasının **Sandbox** sekmesini aç, kendi TikTok hesabını "Test kullanıcıları"na ekle. Onaysız uygulamada yalnızca test kullanıcısı bağlanabilir.

1. `reblebi.com` ana sayfasını göster, giriş yap (panel açılsın).
2. Kanallar sayfasında **TikTok'u bağla**'ya bas.
3. TikTok'un kendi izin ekranı açılsın. İstenen izinleri (profil bilgisi, video yükleme/yayınlama) ekranda 3-4 saniye beklet, sonra **Yetkilendir**'e bas.
4. Reblebi'ye dönünce bağlı TikTok hesabının adı ve avatarı görünsün (user.info.basic).
5. Yeni gönderi oluştur: bir video yükle, TikTok hesabını seç, açıklama yaz.
6. TikTok gizlilik seçimini (Herkes / Arkadaşlar / Sadece ben) ve etkileşim ayarlarını (yorum, düet, stitch) göster. Bunları kullanıcı seçmeli, varsayılan işaretli gelmemeli.
7. **Yayınla**'ya bas. Gönderinin durumunu (işleniyor, yayınlandı) göster.
8. TikTok uygulamasında veya web'de videonun hesapta göründüğünü göster.
9. Ayarlardan **Bağlantıyı kes**'i göster (verinin silinebildiğini kanıtlar).

Not: Video içinde şifre, API anahtarı veya Client Secret ekrana gelmesin.
